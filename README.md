This project focuses on analyzing global weather data to identify trends, correlations, and extreme weather patterns. The dataset was preprocessed and visualized using Power BI to create an interactive dashboard.

🎯 Objectives
    Perform data preprocessing and cleaning
    Identify seasonal patterns
    Analyze relationships between temperature, humidity, and precipitation
    Detect extreme weather events
    Compare hottest and coolest regions

🛠 Tools & Technologies Used
   Python (Pandas, NumPy) → Data preprocessing
   Matplotlib & Seaborn → Data visualization (EDA)
   Power BI → Dashboard creation and interactivity
   
📊 Dashboard Features
   Monthly temperature trends
   Temperature vs humidity correlation
   Precipitation analysis across countries
   Wind speed comparison
   Top 10 hottest and coolest countries
   Drill-through for country-level analysis
   Interactive filters (year, season, country)
